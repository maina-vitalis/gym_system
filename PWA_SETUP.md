# PWA Setup Guide - Tumaini Fitness Management

## What is a PWA?

A Progressive Web App (PWA) is a web application that provides a native app-like experience on mobile and desktop devices. It can be installed on your device, work offline, and provide push notifications.

## Features

✅ **Installable**: Can be installed on mobile and desktop devices  
✅ **Offline Support**: Works without internet connection  
✅ **App-like Experience**: Feels like a native mobile app  
✅ **Fast Loading**: Cached resources for quick startup  
✅ **Responsive**: Works on all screen sizes  
✅ **Secure**: Served over HTTPS

## Installation Instructions

### Mobile Devices (Android/iOS)

1. **Open the app in your mobile browser** (Chrome, Safari, Edge, etc.)
2. **Look for the install prompt** - A banner will appear asking to "Install Tumaini Gym"
3. **Tap "Install"** or "Add to Home Screen"
4. **Find the app icon** on your home screen
5. **Launch the app** - It will open in full-screen mode like a native app

### Desktop (Chrome, Edge, etc.)

1. **Open the app in your browser**
2. **Look for the install icon** in the address bar (usually a computer with a down arrow)
3. **Click "Install Tumaini Fitness Management"**
4. **The app will be added** to your applications/start menu
5. **Launch from your desktop** or start menu

### Manual Installation (if prompt doesn't appear)

#### Chrome/Edge:

- Click the three dots menu (⋮)
- Select "Install Tumaini Fitness Management..."
- Click "Install" in the dialog

#### Safari (iOS):

- Tap the share button (□↗)
- Scroll down and tap "Add to Home Screen"
- Tap "Add" to confirm

2. **Offline Capability**: Continue working without internet
3. **Native Feel**: Full-screen experience without browser UI
4. **Better Performance**: Cached resources load instantly
5. **Push Notifications**: Receive important updates (when enabled)

## Troubleshooting

### Install Button Not Appearing?

- Ensure you're using HTTPS
- Try refreshing the page
- Check if already installed
- Use manual installation method

### App Not Working Offline?

- Ensure you've visited the pages while online first
- Check your browser's storage permissions
- Clear cache and reinstall if needed

### Performance Issues?

- Clear browser cache
- Uninstall and reinstall the PWA
- Check available device storage

## Technical Details

- **Service Worker**: Handles offline functionality and caching
- **Web App Manifest**: Defines app metadata and appearance
- **Cache Strategy**: Network-first with offline fallback
- **Icon Sizes**: Multiple sizes for different devices (72px to 512px)

## Updates

The PWA automatically updates when:

- You're online and refresh the app
- New version is deployed
- Service worker detects changes

No manual updates required!
